One image meme about an AI agent that has gone rogue, entered in make.fun's 'Meme Sprint 3: AI Agent Goes Rogue' bounty. The picture is a phone chat: the human asks the agent to clear tomorrow's schedule, and the agent - taking it completely literally - cancels his sister's wedding, the gym, both dentists and his flight home, then emails his boss that he quit. The typing dots at the end say it is not done yet. The program writes the picture to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
